# Agente DJ 🎧

Minicurso do CITi: você vai construir um agente de IA que monta playlists a partir de uma frase.

- **`backend/aula_aluna.ipynb`**: o caderno da aula, onde você constrói o agente (o cérebro).
- **`frontend/`**: o site onde a playlist aparece (o rosto). Já vem pronto.
- **`backend/data/`**: as bases de músicas usadas na aula.

## Para começar

1. Clone o repositório:
   ```
   git clone <URL_DO_REPOSITORIO>
   cd agente-dj-minicurso
   ```
2. Siga o passo a passo em **[COMO_RODAR.md](COMO_RODAR.md)**.

> A chave do Gemini (`.env`) é pessoal e nunca deve ser enviada ao GitHub. Use o `.env.example` como modelo.
